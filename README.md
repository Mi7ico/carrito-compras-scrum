# Carrito de Compras - Scrum

Este repositorio contiene el desarrollo básico de un proyecto de carrito de compras y la planificación del Sprint N°1 usando Scrum.

## Descripción del proyecto

El proyecto consiste en una aplicación básica de carrito de compras, donde se simula la visualización de productos y la acción de agregarlos al carrito.

## Metodología aplicada

Se aplicó Scrum para planificar el Sprint N°1, definiendo tareas, responsables, riesgos y seguimiento del proyecto.

## Contenido

- Informe del taller práctico en Word.
- Código básico del carrito de compras.
- Archivos de productos y carrito.
